# 中文纯文字剧情导入

推荐策划编辑本目录的 `.txt`，一个角色一个文件。对白、数值与方块图案一起编辑，不需要 JSON、坐标或手填内部 ID。UTF-8 `.md` 也可以导入，但正文仍按下面的标签格式，不要添加 Markdown 标题或代码围栏。

## 导入操作

1. Unity Project 中选中 `Assets/_Game/Data/TaskGrid/StoryConfiguration.asset`。
2. 点击 **导入角色文本（推荐，保留其他角色）**，选择 `.txt` 或 `.md`。
3. 停止后重新运行，或使用游戏重开按钮。导入只替换文件中对应的角色，其他角色保留。支持 Undo。

也可点击 **从角色文本创建新的剧情配置资源**，然后把 `CoreGameplayConfiguration.asset` 的 Story 引用改为新资源。现有 JSON 导入继续可用。本功能不会自动覆盖已导入的剧情。

`快速验证_林小满.txt` 有两次会话，轮数 1 / 3；第一场是正方形，第二场是 L 形，还示范跳转和提前结束。`A_林小满_10次会话.txt`、`B_周序_10次会话.txt`、`C_苏禾_10次会话.txt` 各有 10 次，后期轮数逐渐增加，方便分别协作修改。这些是流程示例，文案和数值尚未平衡。

## 最小格式

```text
角色：林小满
角色ID：A
计算量：30
忍耐时间：90
计算速度：10
Token收入：100
达标能力：写作4，代码1，推理1
优秀能力：写作8，代码2，推理2
方块：
■■
■■

【会话：一句晚安】
【第1轮】
用户：可以跟我说一句晚安吗？

选项1：温柔道晚安
条件：不限
玩家回复：今天辛苦了，晚安。
用户回应：谢谢，明天再聊。
```

- 增加一个 `【会话：标题】` 就增加一次会话。
- 增加一个 `【第2轮】` 就增加一轮，也可用 `【轮次：安慰】` 给轮次命名。
- 增加一个 `选项2：按钮文字` 就增加一个选项。选项数字只帮助阅读，数量按实际内容统计。
- 每个角色的次数、每次的轮数、每轮的选项数均独立，没有统一上限，每层至少一项。

## 默认值与会话覆盖

第一场会话之前填写的数值和方块是该角色的默认值。会话标题之后、第一轮之前填写的值，只覆盖这一次会话；下一次会话重新继承角色默认值，不继承上一次会话的覆盖。

| 标签 | 规则 |
|---|---|
| 角色 | 显示姓名，必填；一个文件只写一个角色 |
| 角色ID | 当前为 A/B/C，对应主玩法请求模板；匹配主配置中的现有唯一姓名时可省略。建议保留，改名也不会影响角色归属 |
| 过往对话 | 可选，放第一场会话之前，可写多行 |
| 任务模板 | 可选，用于继承未填写的参数，默认使用角色 ID |
| 计算量、忍耐时间、计算速度 | 可省略，或填 0，沿用任务模板；其他值须为非负有限数，小数点用 `.` |
| Token收入 | 本次任务的 Token 数量，最终资金按主配置 Token 单价结算；省略继承模板，0 表示无收入 |
| 达标能力、优秀能力 | 例如 `写作4，代码1，推理1`；必须同时存在并包含相同能力类型，优秀值必须大于对应达标值 |
| 方块 | 可省略继承模板；`■` 占格、`□` 空格，也支持 `#` 和 `.` |
| 用户 | 本轮用户发言，必填，放选项之前 |
| 选项1 | 按钮文字，至少一项 |
| 玩家回复 | 可省略，省略时使用按钮文字 |
| 用户回应 | 可省略 |
| 条件 | `不限` / `达标` / `优秀`，省略为不限 |

对白标签后的后续普通行，会作为同一段正文追加；遇到下一个标签或标题时结束。空行仅用于排版。以 `//` 开头的行是注释。中英文冒号都支持；数值标签仍用规定的中文名称，Token收入 的大小写照示例。

方块每行宽度须相同，用空格子补齐；不要在格子字符之间插入空格。至少一个占格，所有占格必须通过上下左右相连，不限四格。过大的形状会被编辑器拒绝（至少一种旋转方向须能放进棋盘尺寸）；当前开放格不足不影响导入，可等升级后摆放。

```text
方块：
■□
■□
■■
```

## 顺序与分支

默认按轮次排列顺序进入下一轮。最后一轮结束当前会话，下次需要新的计算任务。

在某个选项中添加：

```text
跳转到：第3轮
```

即可跳到同一次会话的第3轮。若使用命名轮次 `【轮次：安慰】`，则写 `跳转到：安慰`。同一会话内轮次名称必须唯一；轮次数字不必连续，以实际排列顺序为准。只能跳转当前会话，不能跳入另一会话。

提前结束本次会话：

```text
下一步：结束本次会话
```

也可单独写一行 `结束本次会话`。下一步省略时为下一轮。可以循环跳转，但应保留能结束的选项。

一次会话只计算、提交和结算一次。弹窗内连续选择，经营时间冻结，同次会话共用提交时的质量；选项不会额外增加资金或达标任务数。所有会话结束后，该角色不再生成下一次任务，仍可查看历史。每轮建议至少一个“不限”选项，全部条件挡住时系统会给出顺序推进的兜底回复。

能力类型只有写作/代码/推理/检索，每项分别判断。多轮对白不会自动变得更难，计算难度由你明确填写。只填写文案也可以运行：省略所有数值和方块时继承主配置的对应模板。

新增角色需要先在主玩法配置增加对应请求模板；本次没有改变角色生成方式。文本是编辑器导入源，修改后需再次导入；游戏包不必附带文本，导入的内容保存在剧情配置资源里。历史和进度仅属于本局，重开清空。

导入检查字段、数值、能力、形状、轮次、选项和跳转。错误会尽量指出源文件行号或会话名称；通过整份验证后才替换角色，失败保留目标资源。
