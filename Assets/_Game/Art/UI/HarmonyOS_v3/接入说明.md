# 主界面程序交付 · HarmonyOS Sans

包含9张无文字RGBA UI PNG、6个用户提供的原始TTF、原始LICENSE、文字与布局JSON及字体预览。不含标题Logo、背景、右侧模型，也不再把中文或数字做成切图。

## 字体分工
- Thin：大号节点编号01。Light：等待接入等辅助文字。
- Regular：中英文菜单与SYSTEM READY。Medium：建立连接等主入口。
- Bold / Black：预留给标题层级，不用于大号细数字。
- 六个字重均验证覆盖本页中文、英文字母与数字；无需另外提供英文字体。
- 不使用软件伪粗体。TTF未修改、未裁字、未转换。

## UI与布局
ui/button_*是无箭头底板；arrow_white独立叠加。按钮四态画布一致64×64。
所有PNG背景透明；实心按钮与状态方块自身是不透明的。
layout.json参考1920×1080，原点左上角，文字由引擎渲染；字距单位为px。它是引擎无关的排版参数，需要程序映射到实际UI组件，不是即插即用预制体。
实际文字轮廓与AI效果图略有差异，按真实HarmonyOS字体排版。字体预览仅供检查，不导入运行UI。
建议整体等比缩放适配，数字使用Thin，菜单保持足够字号；长线可以程序绘制。
