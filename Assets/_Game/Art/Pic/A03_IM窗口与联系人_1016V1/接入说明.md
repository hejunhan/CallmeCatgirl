## 使用方式

- 文件不包含姓名、聊天文字、回复文字；由程序使用项目已授权字体渲染，避免缩放模糊和本地化困难。
- 背景铺满屏幕。窗口自带浅色阅读面，不要再把不透明花纹底板盖在整个窗口上；花纹底板供无外框方案使用，或裁切到窗口内容区内。
- PNG 使用透明通道，勿使用颜色键抠图。窗口仅外侧角落透明，中心阅读区不透明，这是预期行为。
- 窗口九宫格边距：左/上/右/下各 100 px；内容距边至少 112 px。两种高度均用九宫格生成，角部尺寸一致。建议最小 400×240。
- 气泡、按钮、回复区：九宫格边距各 16 px；头像框各 12 px。头像、状态图标、勾选图标保持等比缩放。
- 气泡内部文字建议水平 24 px、垂直 16 px 留白。消息内容撑高底板，不要拉伸文字。参考 1920×1080 下正文 26–30 px，姓名 22–24 px，提示 18–20 px。
- 回复按钮文字建议距左 32 px，右侧为独立勾预留 64 px。勾必须独立叠加，按钮贴图没有烘焙勾。
- normal 普通；hover 悬停；pressed 按下；selected 持续选中；disabled 禁用。选中和按下用浅色文字 #FFFFFF，普通和悬停用 #252729，禁用用 #85827E。交互优先级建议 disabled > pressed > selected > hover > normal。
- online 为绿灰实心圆加勾；offline 为灰色空心圆；busy 为香槟色减号圆；unread 为石墨色圆点。不要仅靠颜色判断状态，配合状态文字。
- 推荐图层：背景 → IM 窗口 → 气泡 → 消息文字 → 回复区 → 回复按钮 → 按钮文字/选中勾 → 头像与联系人状态。
- Unity 可导入为 Sprite/UI，Mesh Type 使用 Full Rect，边框按 manifest.json 设置，Image Type 使用 Sliced；关闭 Mipmaps。其他引擎按同样边距使用九宫格。最终仍需在实际引擎确认 DPI、字体、缩放和输入状态。

## 交付边界

本包是静态素材和参数，不包含引擎预制体、交互代码或角色专属头像；通用头像为中性用户剪影。没有新增联系人侧栏，维持已确认的上下分区原型。

生成背景原图为 1672×941，已高质量缩放至 1920×1080；窗口经裁切、圆角边缘清理和九宫格输出到指定尺寸，并非原生 1920 渲染。source 保留原图。尚未在游戏引擎内验证。

生成方式：内置 imagegen 用于背景与窗口材质；扁平控件为程序绘制并导出透明 PNG。组件预览.jpg 仅供查看，勿作为图集导入。
