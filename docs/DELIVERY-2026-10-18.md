## 尚未证明与功能差异

没有启动独立 QA Player，也没有进行本机实际全屏、显示切换、音量输出或 FPS／VSync 运行验收。设置测试使用假后端，离屏画面属于 Editor 批处理。四种结局均已通过批处理中的完整真实经营与菜单续玩；这不等于实际桌面验收。另三条路线均在首月结束，没有证明跨月维护费平衡，显式提交收入也不包含合法的超时部分结算收入。

人工核对了全部 1280×720 画面及关键 1920×1080 画面。政策卡片正文在离屏图中仍偏软，等待真实 Player 帧后仍未改善；目前没有证据确认原因。它保留为画面清晰度待核项，不能把几何可见性通过写成所有视觉质量已通过。

模型稳定 ID 保持 `baseline`、`alternate`、`architecture-slot-3`，标题为 Transformer、MoE Transformer、协调状态架构，正常在 1／2／4 物理 RAM 解锁；0 RAM 仅有教程例外。Unity 四域为写作／代码／推理／检索，与 Web 的写作／推理／共情／知识尚未统一。政策终局没有擅加 RAM5 门槛。数值为可验证候选，未声称最终平衡。
