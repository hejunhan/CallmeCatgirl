# 内存隔板与背包配置

选中 `Assets/_Game/Data/TaskGrid/MemoryUpgradeConfiguration.asset`，所有设置仍在这一份资源中。

1. **解锁等级**：选初始、2级、3级等，点击或拖动涂格子，决定各次升级开放的位置。
2. **背包分区 / 隔板**：选择或输入背包编号，点击或拖动涂格子。相同编号属于同一个背包，不同编号之间自动产生隔板。0也是有效背包，不是锁定。
3. **按等级预览**：拖动等级滑条，查看该等级开放的格子、隔板和背包数量。深色为未开放，格子里的编号表示背包，白色粗线表示分界。

“新背包 +”选择未使用编号；“上下切分 / 左右切分”按填写的行或列切成两包，“合成一个背包”取消所有内部隔板。这三个操作只改分区，不改升级价格、奖励或格子开放等级。支持 Ctrl+Z。

## 放置规则

- 一个任务形状的**每个占用格**都必须开放、没有其他任务，并属于**同一个背包编号**。
- 隔板不占格子、不消耗时间或资金；任务不能跨隔板，即使两边都已开放。
- 方块可整体移动到另一背包，也可旋转；非法落位或旋转保留原位置、进度、能力和占格。拖拽预览与最终落位共用同一判断。
- L形等只检查实际占用格，不要求空白的包围矩形全部属于同一背包。建议把同一编号涂成相连区域，避免配置成多个相隔的区域。
- 升级只增加开放格子，隔板不随等级改变，所以不会把已经运行的任务拆开。配置在重开时读取，运行时修改需重开。

## 当前示例

8×8棋盘在**第4列与第5列之间**放一条竖隔板：左方为0号背包，右方为1号背包。保留原有解锁位置、升级价格、完成任务门槛和奖励点数。

- 1级：原来的18格分成左右两个3×3小背包，初始任务都能找到完整落位。
- 2级：各背包向上扩容；3级补齐宽度并向下扩容；4、5级继续向下开放。
- 横向长条跨第4、5列会被拒绝。可旋转后放进单个背包。

想升级时开放一个全新小背包：先把那片锁定格涂成新的背包编号，再在“解锁等级”里把它们涂成对应等级即可。想扩容旧包：使用旧包编号。

旧配置没有分区数据时默认全部属于0号背包；四参数 `TaskSimulation` 构造调用保持兼容，新增的第五参数为按行排列的分区编号数组。美术可以在场景中替换 `BoardPartitions` 和 `PreviewPartitions` 的图层样式，粗线颜色及宽度不影响判定。
