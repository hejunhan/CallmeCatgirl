# 游戏日历与维护费

主配置：`Assets/_Game/Data/TaskGrid/CoreGameplayConfiguration.asset`。

- 每天游戏秒数：120，即2分钟游戏时间。
- 每月天数：30，因此每月3600秒，即1小时游戏时间。
- 每月维护费：1500，只在月底结算，每天不扣维护费。
- 资金不足可拖欠一次：先扣完现有资金，将差额记为欠款，继续经营一个月。下月底需要支付未还差额和当月1500；还清则解除宽限，仍不足则停机。
- 暂停冻结日历，0.5×/1×/2×/4×作用于同一游戏时钟。0.5×时一天实际4分钟；1×时实际2分钟。
- 月末任务刷新依旧按月触发。请求原有忍耐时间、计算速度不变。
- UI 显示当前月、当前天、当天剩余时间。天数由已有月内计时推导，保存读取不会重置天数。

修改时间或费用配置后请重新开局。原存档仍受内容版本检查保护，不会按新日历静默重新解释。
