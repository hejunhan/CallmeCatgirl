## 首个可玩版本

先验证一条完整的玩家流程，再扩展内容。

1. 进入测试场景，能理解当前目标。
2. 完成一种核心操作，看到明确反馈。
3. 面临至少一个有意义的选择或挑战。
4. 达到成功、失败或阶段结束条件。
5. 能重新开始并再次验证同一流程。

实际实现时，将以上条目替换成具体规则、数值和操作说明。
战斗、背包、任务、对话、养成等模块是否需要，由这个流程决定。

## 阶段顺序

- 工程准备：目录、版本管理、打开项目的说明。
- 核心原型：确定玩法并实现一个可反复验证的完整流程。
- 最小可玩版本：补齐必要界面、反馈以及明确的开始和结束。
- 内容扩展：核心流程验证后，再增加关卡、资源和系统。

以上是开发顺序，不是功能完成声明或工期承诺。

## 已实现的核心玩法（2026-10-10）

- 任务摆放、90度旋转、原子移动、撤回、截止超时和确认提交。
- 独立计算速度、模型定频能力累计、逐项门槛与最低质量档判定。
- 全局暂停、1/2/4倍速以及模拟回复后进入下一轮。
- 验收：非法移动不损坏占格；要求10/2/2与产出12/3/3通过，12/1/10不通过；算完仍占格，提交仅结算一次。
- 测试数据、接口、未定规则的暂行口径与范围详见 CORE_GAMEPLAY.md。
