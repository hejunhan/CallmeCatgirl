## 首个可玩版本

先验证一条完整的玩家流程，再扩展内容。

1. 进入测试场景，能理解当前目标。
2. 完成一种核心操作，看到明确反馈。
3. 面临至少一个有意义的选择或挑战。
4. 达到成功、失败或阶段结束条件。
5. 能重新开始并再次验证同一流程。

实际实现时，将以上条目替换成具体规则、数值和操作说明。
战斗、背包、任务、对话、养成等模块是否需要，由这个流程决定。
