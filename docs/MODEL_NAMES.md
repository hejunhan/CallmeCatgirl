# 升级后的模型名称

选择Assets/_Game/Data/TaskGrid/MemoryUpgradeConfiguration.asset：

- 初始模型名称：开局/重开时ModelInfo显示的名字，当前示例为“小猫 Lv.1”。
- 展开Levels，在每档的“升级后的模型名称”中填写新名字，已提供“小猫 Lv.2”到“小猫 Lv.5”的示例，可自由替换。
- 升级成功后立刻显示该档名字；升级失败保持原名，加点也不会改名。重开后恢复初始等级对应名称。
- 名称留空沿用最近一个已配置的低等级名字，初始名也留空则使用原模型标识。档位顺序不影响名称选择；直接以较高初始等级开局会采用该等级对应名字。

这是独立的显示名称，计算系统的模型ID、能力值、周期、任务进度、升级价格、奖励点数及棋盘布局保持原样。旧资源没有名字字段时保持原来的显示行为。
