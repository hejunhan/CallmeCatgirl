# Game Jam 最终试玩

环境：Unity 6000.5.2f1，CoreGameplay；由实际主菜单 StartNewGame 按钮进入新局。通过 Unity MCP 调用游戏控件事件与正常命令，未操作用户鼠标，未导出构建或跑全套测试。

结果：本次流程未发现明显阻断问题，Unity Console 为 0 条 error。

- 新局候选双击打开所属 IM，模块原位不变；尚未计算完成时不能通过回复跳过运算。
- IM 开着时成功 BeginDrag/EndDrag 放置 B 模块，棋盘模块双击打开同一会话；可旋转后继续计算。
- 点击实际回复按钮完成交付，首轮资金增加 100、语料增加 1；重复旧回调不重复结算。
- 同会话第二轮正常计算、回复并累计 2 条语料；保留 B / B-1 与 B-round-1 / 各 round、node、choice 来源。三个能力各累计 4 分，仍使用原可调要求回退评分。
- 普通会话结束概率第一轮 .045、第二轮 .07；本次第二轮抽样 .004830717574805021，实际命中结束。回复完整完成后会话结束。
- 运行中开关 IM 时间继续推进；手动暂停中开关 IM 保持暂停。无阅读剧情标签或模态阻断。
- 升级页确实拦截输入并关闭工作区 CanvasGroup 交互，关闭后恢复；IM 自身稳定帧 raycast 优先命中窗口区域，不穿透到底下棋盘。
- 使用独立 QA 存档槽保存，回真实主菜单，通过 ContinueSlot 继续。恢复资金 1700、已完成 2、语料 2、会话结束状态、池绑定 sample-02、历史和随机状态；手动暂停保持，无重复奖励。QA 存档未纳入版本控制。
