# 任务形状和月度刷新配置

## 配置入口与本次默认值

| 设置 | 所在资源与字段 | 当前值 | 调整方式 |
|---|---|---|---|
| 一个月的游戏时长 | `CoreGameplayConfiguration.asset` → 每月游戏秒数 | **30秒** | 改这个字段；月度结算和刷新共用同一时钟 |
| 每次新增请求数 | `TaskGenerationConfiguration.asset` → 每次新增请求数 | **5个** | 改数量，0关闭自动刷新 |
| 刷新周期 | 同上 → 每隔多少个月刷新 | **1个月** | 如改2，则默认每60游戏秒新增一批 |
| 预设形状数量 | 同上 → 随机形状库 | **10种** | 可新增、删除，不限制必须10种 |
| 随机种子 | 同上 → 随机种子 | **-1** | 负数每次开局重新随机；非负数用于复现 |

主配置的“任务生成与方块配置”已引用新资源。资产位于 `Assets/_Game/Data/TaskGrid/`。修改后重开游戏生效。原有资金、月维护费、任务计算量、速度、能力门槛、Token及忍耐等数值保持原配置。

初始仍创建原有角色的请求。第30游戏秒进入第2月时新增5个，第60秒再次新增5个，以此类推。以游戏时间计数，受0.5/1/2/4倍速影响；默认0.5倍速时30游戏秒约为60现实秒。全局暂停、阅读剧情和内存升级弹窗会冻结月度/刷新时钟。

## 形状优先级

1. 当前会话导入了方块图案（包括角色级默认图案），使用该图案。
2. 当前会话没写图案，从独立随机形状库中等概率选择一种。
3. 未指定任务生成配置的旧配置，继续兼容原来的模板形状。

一个任务在创建时抽取一次形状，之后拖拽、刷新界面、计算、多轮回复都不会重新抽取。下一次会话是新任务，可以再次抽取。抽取允许重复，五个请求之间也可能拿到相同形状。

旧 `Requests.Shape` 向量数据保留作兼容，并从默认Inspector隐藏；新的设计在独立资源或剧情图案里完成，不必维护两套方块。

## 可视化编辑

选中 `TaskGenerationConfiguration.asset`，展开任意形状：

- 修改“形状名称”，设置行数、列数。
- 点击小棋盘切换占格；紫色方块表示占用，空白表示不占用。
- 支持Ctrl+Z撤销；“新增形状”和“删除”可调整库大小。
- 占格必须通过上下左右连接，且至少有一个占格。错误图案会提示，开局也会校验。

默认10种为单格、双格、三格直线、三格转角、四格正方形、四格T形、四格L形、四格S形、四格Z形、五格十字。全部的外接尺寸不超过3×3，默认初始小背包可容纳。自定义更大的形状时，应同步安排内存开放与背包尺寸。

## 新增与超时

月度刷新**新增**请求，保留原来的等待、计算和待提交任务。每个任务仍从自身到达时间开始计算忍耐；超时后退出候选栏/释放占格，历史记录和结算状态保留，不整批强制删除。

自动新增使用现有“新请求”的独立用户机制：为每个请求生成唯一用户ID，随机选择主配置中的任务数值模板，再从形状库选择形状。原有固定角色仍按导入剧情逐次推进，不被新增请求覆盖。自动刷新不会抢走当前选中的任务。

月份边界先推进旧任务、处理结算，再扣月维护费；服务器仍可经营时才新增下一批。跨多个月的大步长会分别在正确的到达时刻生成各批，而不会把全部请求挤在同一时刻。经营失败后停止刷新。
