## 有复现证据的修复

| 问题 | 原行为与证据 | 修复 |
| --- | --- | --- |
| 显示确认的键盘隔离 | `unity-ux-02`：确认层后的 Slider 仍可交互；确认按钮向上导航会选择遮挡层外的控件。 | 设置面板在预览期间禁用输入；确认与恢复按钮显式约束方向导航，取消后恢复。 |
| 旧焦点失效 | `unity-ux-02`：设置关闭后重新选择已不可交互的旧按钮。 | 共用有效性检查同时验证显示、组件启用及可交互性；有效旧焦点仍正常恢复。 |
| 保存回调重入 | `unity-ux-02`：回调重入导致两次保存／导航尝试。 | 菜单会话拥有同步重入保护，`finally` 释放；失败保持暂停与错误，后续主动重试可用。 |
| 窄聊天窗关闭按钮越界 | `unity-ux-04`：420×340 窗口的关闭按钮超出右边界约 208 像素。 | 标题、结果和关闭按钮改用响应式锚点，共用一处头部布局。 |
| 视口缩小后窗口滞留 | `unity-ux-04`：1920×1080 改为 800×450 后，原固定尺寸窗口仍伸出视口。 | 同时观察窗口和父视口尺寸，先缩到可用范围再夹回边界、重排文字。 |
| 拖动归属与结束 | `unity-ux-04`：另一指针或结束后的同一指针仍能移动窗口。 | 明确开始、指针归属、结束／禁用／失焦释放；有效指针拖动和缩放保持可用。 |
| 长剧情选项焦点不可见 | `unity-ux-04`：四十行夹具中的真实选项收到选择事件后仍在视口下方。 | 抽取共用滚动焦点组件；旧设置组件名称及 GUID 保留兼容。可收起的长对话初始保留正文开头，选择选项时滚入可见区域。 |

结构整理限于共用滚动行为、共用聊天头部布局、焦点有效性检查及拖动角点缓冲复用，移除不再使用的固定定位函数。没有改写游戏状态或存档体系。
