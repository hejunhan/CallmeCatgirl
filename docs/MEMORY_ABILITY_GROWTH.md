# 内存升级奖励与玩家加点

策划只在 `MemoryUpgradeConfiguration.asset → Levels → 奖励能力点数 AbilityPoints` 填写每档奖励。旧的指定能力增长列表已移除；当前档位按原增长总量迁移，升 Lv2/Lv3/Lv4/Lv5 分别奖励 7/4/4/8 点，原费用、条件和格子保留。

玩家确认内存升级时开放格子、扣一次费用并获得点数，模型能力此时保持原值。在同一弹窗点击写作/代码/推理/检索的 +1 按钮自由分配，1 点使该能力的每周期产出增加 1。玩家可以全投一项或分给多项，不额外扣资金。

未分配点数可留存，关闭弹窗不丢失，后续等级奖励继续叠加。内存满级后仍可打开弹窗分配剩余点数。零点禁用加点按钮；奖励为0表示只扩容；非法奖励或余额溢出会阻止升级。没有配置初始加点奖励。

每次加点立即应用，不提供返还/洗点。期间经营时间冻结，运行/暂停状态保留；已累计任务能力、计算进度、周期余量和已完成任务质量保持，后续周期及新任务使用新产出。重开恢复初始 ModelPoints、清空点数，本局暂未接磁盘存档。

加点控件是 CoreGameplay 场景中真实 Canvas 对象，位于 MemoryUpgradePopup/Window，可直接替换样式和美术。运行时代码只读取绑定并更新文字/按钮状态。

使用临时项目和固定的主玩法参数/空剧情列表进行基线回归；原项目主配置与剧情按 SHA-256 核对未变。用户当前初始能力仍为1/1/1/0。内存资源仅把原增长列表总量转换为7/4/4/8奖励点数；原价格、条件、格子及GUID保留。
