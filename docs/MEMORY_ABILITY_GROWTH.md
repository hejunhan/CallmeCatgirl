# 内存升级与模型能力

内存升级不再奖励能力点，也不提供属性加点按钮。模型能力通过对话语料训练、完成训练后启用模型来提升；训练的投入点数是语料点数，不是内存升级点数。

`MemoryUpgradeConfiguration.asset` 继续配置升级费用、达标任务条件、开放格子、隔板和新请求倍率。内存安装小游戏完成或跳过并通过校验后，才扣费并扩容；取消或失败不扣费。升级不会增加模型能力。

旧存档已形成的模型能力保持原样，不追溯扣减。旧的未分配能力点不再生效，新存档将历史余额写为 0。配置中隐藏的历史字段仅为维持存档内容版本兼容，不显示在 Inspector，也不参与任何奖励或加点计算。

界面使用场景中保存的内存布局、升级条件和安装入口；原加点控件及运行绑定已删除。
