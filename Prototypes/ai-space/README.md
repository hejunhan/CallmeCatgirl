# AI空间经营 · 可丢弃玩法原型

双击 index.html 即可运行，无安装、无需联网。来源：C:\unity\CallmeCatgirl\test.txt，2026-10-05。

验证问题：拼放与优先级是否好玩；为处理复杂请求增加的空间和时间是否值得；记忆、经验和成长是否改变之后的选择。

操作：
- 开始本轮，卡片拖入棋盘。R旋转。运行中的任务可以移动，或拖回左侧撤回。
- 撤回保留当前步骤和进度；期限继续；非法落下恢复原位。
- 完成后左侧回复用户。先选方案后放入，一旦开始运行便锁定方案与模型等级。
- 快速工作台组合获取、检查、读写和返工次数，保存后自动复用。没有自由端口连线，布局自动压成2或3格宽。
- 验证开关可关闭格子经验、客源偏向或显示真实难度。调试按钮用于手动推进状态，不属于正式暂停玩法。

模式：
1. 基础排程：90秒，结果固定为成功（期限内），只比较摆放与撤回。
2. 流程模式：90秒，5个预设＋自定义。获取／命中记忆补1级，修正补级但总能力最高为模型＋2。检查本身不补级；生成3秒、修正2秒、获取4秒、检查2秒、读写各1秒。所有安装模块始终占格，各实例独立运行。
3. 原文A/B/C：4×3棋盘。A、B第0秒到达，C第2秒到达。A放左上，B放底行；第2秒撤B放C到右侧，第8秒再放B。应得到A第10秒成功、C第7秒成功、B第12秒失败，B收费60token。

简化：
- 一切状态在内存，刷新清空；没有真实AI、联网、App调用或Unity依赖。
- 记忆精确匹配类型／难度／资料版本，65秒过期、最多6条。这模拟属性匹配，不做语义检索。
- 格子经验最多2层／16%加速；成功后留下类型。声望影响之后客源。3份语料＋8币提升某项模型等级，仅影响新启动请求。
- 生成阶段计对外token；内部返工不重复计费。流程模式售价0.1币/token，执行中单元0.1币/格/秒，终结时结算。
- 基础模式和流程模式耗时与质量规则不同，应比较操作体验，不能直接用两模式利润证明哪种更好。
- 危险请求剧情、实际模型训练、自由流程图和多结局留到之后。
- 原文“只完成文档”的旧范围被本次“立即制作验证”的明确请求取代。

### 观察与暂停
默认0.5倍速，可切换0.25／0.5／1倍。点击棋盘任务后使用“暂停此任务／继续此任务”。暂停保留进度、继续占空间，不增加费用和token，但期限继续。撤回、重新放置保留暂停状态。顶部全局暂停冻结所有计时，供观察流程使用。
